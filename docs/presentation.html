Interview Prompt

Scenario

Our business-critical desktop application runs across enterprise Windows and macOS endpoints, where direct customer access for real-time troubleshooting is highly restricted. To scale support, we need to design a Log Analytics and Resolution Portal that ingests and parses continuous log streams (raw text, Windows Event Log, macOS unified logs) sent by customers or support agents, mapping them back to our application's source logic.

The Challenge

How would you architect this portal to automate the troubleshooting lifecycle?

Explain how the system will analyze log patterns to provide customers with immediate, actionable self-service resolutions for known issues.

Additionally, if the log indicates an unknown or ambiguous failure, how would you design a smart diagnostic mechanism that automatically determines exactly what is missing and generates a targeted request for specific telemetry, configuration files, or state data?

Evaluation Criteria

  • Ability to explore the problem statement
  • Creativity/novelty in approach
  • System design
  • Completion of the solution

Why Signature Matching over ML?

👁️ Interpretable — See exactly why an issue matched
🎛️ Controllable — Add/edit/remove without retraining
🚀 No cold start — Works day one, no training data needed
💡 Future: ML can catch unknown patterns once we have labeled data from resolved issues

Demo

1. Request Additional Data

sequenceDiagram
    participant Agent as 🖥️ Endpoint Monitor Agent
    participant Hub as 🌐 Self-Service Resolution Hub
    participant Engine as 🔍 Intelligent Triage Engine

    Hub->>Engine: Support/Dev engineer creates config (collect System Info)
    Agent->>Engine: On startup, fetch configs
    Note over Agent: Issue triggered
    Agent->>Engine: Send logs + System Info
    Note over Engine: Create issue ticket
    Hub->>Engine: Support/Dev engineer reviews, needs Uptime
    Hub->>Engine: Support/Dev engineer updates config to collect Uptime
    Engine-->>Hub: Notify Admin: configs changed
    Hub-->>Agent: Admin pushes configs update
    Note over Agent: Another issue triggered
    Agent->>Engine: Send logs + System Info + Uptime

2. Existing Issue Auto-Resolved on New Signature

sequenceDiagram
    participant Agent as 🖥️ Endpoint Monitor Agent
    participant Hub as 🌐 Self-Service Resolution Hub
    participant Engine as 🔍 Intelligent Triage Engine

    Note over Hub: Support/Dev engineer reviews hang issue
    Note over Hub: Engineer fixes issue in app code
    Hub->>Engine: Engineer creates signature for hang issue
    Hub->>Engine: Engineer requests signature matching on existing issues
    Note over Engine: Hang issue matches new signature
    Engine->>Engine: Update issue to 'Resolved' (resolution: update product)
    Engine-->>Hub: Notify Admin on issue resolved

3. New Issue Auto-Resolved on Existing Signature

sequenceDiagram
    participant Agent as 🖥️ Endpoint Monitor Agent
    participant Hub as 🌐 Self-Service Resolution Hub
    participant Engine as 🔍 Intelligent Triage Engine

    Hub->>Engine: Engineer creates signature for 'vpn connection' issue (resolution: KB article)
    Note over Agent: VPN connection issue triggered
    Agent->>Engine: Collect and send logs
    Note over Engine: Create issue ticket
    Note over Engine: Check logs against signatures - match found
    Engine->>Engine: Update ticket to 'Resolved' (resolution: KB article)
    Engine-->>Hub: Notify Admin on issue resolved
